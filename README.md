How to install this skin:

To install this skin, you need to copy and paste it into a new skin form for your own personal use.

Click on your username and go to your dashboard.
Click "Skins" on the left menu.
Click the "Create Site Skin" button on the right hand side.
Be sure the settings are set to Site Skin, give it a name, and paste the code in the box which says CSS. 
Save it!
Then from the created page or back oon your Skins menu, select the "Use" button.
Done!
You may use this same screen to revert it by selecting "Stop using"
